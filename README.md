\# Sales Data Analysis using SQL



\## Project Overview

This project analyzes sales data using SQL queries.



\## Dataset

The dataset contains:

\- Order ID

\- Product

\- Category

\- Customer

\- Amount

\- Order Date



\## Analysis Performed

\- Total sales

\- Top selling products

\- Category wise sales

\- Top customers

\- Monthly sales trends
