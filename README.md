# Sales Data Analysis using SQL



## Project Overview

This project analyzes sales data using SQL queries to generate meaningful business insights.
It demonstrates SQL concepts such as data retrieval, filtering, aggregation, grouping, sorting, and conditional logic.


## Dataset

The dataset contains 50 sales records with the following columns:

- Order ID

- Product

- Category

- Customer

- Amount

- Order Date


## SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- HAVING
- ORDER BY
- SUM()
- AVG()
- COUNT()
- DISTINCT
- CASE
- LIMIT


## Analysis Performed

- Total sales

- Top selling products

- Category wise sales

- Top customers

- Monthly sales trends

- Highest sale

- Products in electronics category

- sales above 30,000

- Average Sales
  
- Total number of orders
  
- Distinct customers
  
- Category-wise sales using having
  
- Sales classification using cASE statement
